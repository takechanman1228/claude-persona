# Running Shoes — Full-Fable Edition

This directory is the **Claude Fable 5 edition** of the [running shoes demo](../README.md):
**both the persona panel and the survey responses were produced by `claude-fable-5`**
(the main demo uses an April 2026 panel answered by `claude-sonnet-4-6`).

Provenance is verifiable in the committed files:
- `personas/manifest.json` → `"generated_by": "claude-fable-5"`
- `concept-test/results/run_metadata.json` → `"actual_model_ids": ["claude-fable-5", ...]`

Same brief, same three concepts, same engine settings — only the model changed,
for panel generation and for answering. Concept test only (no `ask` run in this edition).

## Results

- **B: Soft Cushion Support** — **9/15 (60%) first choice**
- **C: Versatile Style** — 4/15 (27%)
- **A: Lightweight Comfort** — 2/15 (13%)
- **Purchase likelihood**: mean 3.53/5

Same winner as the published sonnet demo (B7/A5/C3), with a wider margin:
this Fable-built panel skews harder toward comfort-and-health buyers
(post-op, on-feet-all-day, doctor's-orders archetypes) and includes more
style-first non-runners, moving votes from A to B and C. See the
[model sensitivity study](../../../docs/MODEL-COMPARISON.md).

Run: 15/15 personas, all first-attempt valid, adherence 8–9/10,
$2.88 API-equivalent, 82 s wall clock.

## Reproduce

```bash
python scripts/simulate_survey.py --config demo/running-shoes/fable/concept-test/config.json --analyze
```

(Requires the `fable` model alias — Claude CLI 2.1.170+. Costs ~3–3.5x a
sonnet run; on subscription auth it consumes usage limits instead of billing.
Note this overwrites `concept-test/results/`.)
