# Gen Z Skincare — Full-Fable Edition

This directory is the **Claude Fable 5 edition** of the [Gen Z skincare demo](../README.md):
**both the persona panel and the survey responses were produced by `claude-fable-5`**
(the main demo uses an April 2026 panel answered by `claude-sonnet-4-6`).

Provenance is verifiable in the committed files:
- `personas/manifest.json` → `"generated_by": "claude-fable-5"`
- `concept-test/results/run_metadata.json` → `"actual_model_ids": ["claude-fable-5", ...]`

Same brief, same three concepts, same engine settings — only the model changed,
for panel generation and for answering. Concept test only (no `ask` run in this edition).

The published sonnet demo landed on an A/B **tie** (4/4/2); the full-Fable
edition resolves it into a clear B win — consistent with the
[model sensitivity study](../../../docs/MODEL-COMPARISON.md), where Fable
sharpened this same close race on the April panel too (B6/A3/C1).

## Reproduce

```bash
python scripts/simulate_survey.py --config demo/genz-skincare/fable/concept-test/config.json --analyze
```

(Requires the `fable` model alias — Claude CLI 2.1.170+. Costs ~3–3.5x a
sonnet run; on subscription auth it consumes usage limits instead of billing.
Note this overwrites `concept-test/results/`.)
