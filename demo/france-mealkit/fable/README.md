# France Meal Kit — Full-Fable Edition

This directory is the **Claude Fable 5 edition** of the [France meal kit demo](../README.md):
**both the persona panel and the survey responses were produced by `claude-fable-5`**
(the main demo uses an April 2026 panel answered by `claude-sonnet-4-6`).

Provenance is verifiable in the committed files:
- `personas/manifest.json` → `"generated_by": "claude-fable-5"`
- `concept-test/results/run_metadata.json` → `"actual_model_ids": ["claude-fable-5", ...]`

Same brief, same segment definitions (4 DINK couples / 3 families with young
children / 3 independents & empty nesters), same three concepts, same engine
settings — only the model changed, for panel generation and for answering.
Concept test only (no `ask` run in this edition).

## Results — the most instructive demo in the set

- **C: Better Weeknights Fast** — 4/10 (40%) first choice
- **A: Easy First Step** — 3/10 (30%)
- **B: Risk Reduction** — 3/10 (30%)
- **Purchase likelihood**: mean 3.0/5

**A three-way split — and the only demo where the winner moved.** The
published sonnet demo says B7/C3/**A0**; the April panel answered by Fable
already softened that to B4/A3/C3; and this freshly generated panel lands
C4/A3/B3. Taken together, the three conditions show these concepts are
genuinely close and the striking "concept A got zero votes" finding was a
property of one panel, not of the market. This is exactly the kind of result
that should be read as "no clear winner — pressure-test with a follow-up
`ask`" rather than as a mandate. Full analysis in the
[model sensitivity study](../../../docs/MODEL-COMPARISON.md).

Run: 10/10 personas, all first-attempt valid, adherence 8–9/10,

## Reproduce

```bash
python scripts/simulate_survey.py --config demo/france-mealkit/fable/concept-test/config.json --analyze
```

(Requires the `fable` model alias — Claude CLI 2.1.170+. Costs ~3–3.5x a
sonnet run; on subscription auth it consumes usage limits instead of billing.
Note this overwrites `concept-test/results/`.)
